Privacy

Last updated 2026-10-08. cmm.dev is a static personal website run by Chris McConnell. It exists to list his projects and background. It does not sell anything, and it does not need to know who you are.

What this site collects

Nothing on purpose. The site sets no cookies, runs no analytics or tracking scripts, loads no third-party fonts or embeds, and has no forms or accounts. The only JavaScript is a small file that moves the on-screen windows around; it sends no data anywhere.

What the host records

The site is served by Cloudflare Workers. Like any web host, Cloudflare receives your IP address, user agent, and the pages you request in order to deliver them, and keeps short-lived edge logs for security and reliability. Cloudflare's handling of that data is described in its own privacy policy. Chris does not export or analyze those logs.

Outbound links

Links to GitHub, LinkedIn, Buy Me a Coffee, Eagle Ridge Advisory, and Humaine Studio take you to sites with their own privacy practices. This policy covers cmm.dev only.

Changes and questions

If the site ever adds analytics or a contact form, this page will say so with a new date. Questions go through the channels on the contact page.
